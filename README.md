# Fable Notes

A cute paper-stack notes widget for Android (square, resizable).

## Install
1. Download `FableNotes.apk` from this repo's **Releases** and install it.
2. Long-press your home screen → **Widgets** → **Fable Notes**, and drop it on a home page (3×3 looks best; 2×2 works).

## Use
- **Tap a note's title** on the widget to slide to the next note.
- **Tap a line** to strike it off with an ink scribble. Tap again to bring it back.
- **Tap the title or an empty line** to open that note and edit it. New notes are made in the app.
- In the app: pick a handwriting (Kaushan, Kalam, Caveat, Patrick Hand) and a paper colour per note.

Android 12 or newer. Built automatically by GitHub Actions on every push.
